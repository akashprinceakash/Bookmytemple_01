
  # BookMyTemples

  Figma design - https://www.figma.com/design/5klaGlAwEgHgtrOpYdyUkl/Booking-Website.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Build
  
   Run `npm run build`

   ## Deployment
   
   `swa deploy ./build --deployment-token <TOKEN>`
